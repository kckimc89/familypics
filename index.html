우리 가족의 사진묶음

목록을 불러오는 중입니다.

묶음을 누르면 상세 내용과 관리 기능이 열립니다. 본인이 만든 묶음은 「이름·분류 수정」을 누르고 「변경 저장」으로 수정할 수 있습니다. 삭제는 관리자 또는 만든 사람만 가능하며, 나중에 다른 가족의 사진이 포함된 묶음에는 추가 보호를 적용합니다.

🖼️ 사진묶음 연습

🔒 서버에 올리지 않는 시험용 화면입니다. 사진묶음 만들기 → 파일 여러 개 추가 → 다른 파일 추가 → 감상·제외를 시험합니다. 실제 공동 공유가 아니며 닫으면 모두 사라집니다.
